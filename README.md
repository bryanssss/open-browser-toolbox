## 🔒 Privacy

Most inputs are processed entirely inside the visitor's browser. Uploaded images are handled with browser canvas and are not uploaded to an OpenToolbox application server.

Two tools use external resources:

- **Currency Converter:** requests reference exchange-rate data from the Frankfurter API.
- **QR Code Generator:** loads the MIT-licensed QRCode.js library from jsDelivr before rendering locally.

GitHub Pages may process normal hosting logs under GitHub's own policies.

## 🖥️ Run Locally

You can double-click `index.html`, although service-worker and API features work best through a local web server.

With Python installed:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000/
```

## 🚀 Publish with GitHub Desktop

1. Extract the downloaded ZIP.
2. Open **GitHub Desktop**.
3. Select **File → Add local repository**.
4. Select the extracted `open-browser-toolbox` folder.
5. When GitHub Desktop says it is not yet a repository, select **create a repository**.
6. Keep the repository name exactly `open-browser-toolbox`.
7. Set the description to: `84 free, privacy-focused browser tools for text, development, design, conversions and everyday calculations.`
8. Choose **MIT License** only if GitHub Desktop asks and the existing files are not being replaced.
9. Select **Create repository**.
10. In the bottom-left summary box, enter `Initial OpenToolbox release`.
11. Select **Commit to main**.
12. Select **Publish repository** at the top.
13. Keep the name `open-browser-toolbox`.
14. Untick **Keep this code private** so GitHub Pages can publish it on a free account.
15. Select **Publish repository**.
16. Open the repository on GitHub.com.
17. Select **Settings → Pages**.
18. Under **Build and deployment**, choose **Deploy from a branch**.
19. Select branch **main** and folder **/(root)**.
20. Select **Save**.
21. After GitHub finishes the deployment, visit `https://bryanssss.github.io/open-browser-toolbox/`.

## 🔧 Change the GitHub Username or Repository Name

The generated canonical URLs, sitemap and README currently use:

```text
GitHub username: bryanssss
Repository: open-browser-toolbox
```

When either value changes, update these files:

- `README.md`
- `robots.txt`
- `sitemap.xml`
- GitHub links in the shared header and footer inside the generated HTML files
