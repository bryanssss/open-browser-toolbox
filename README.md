## 📖 About OpenToolbox

OpenToolbox brings **84 useful online tools** together in one fast, searchable and mobile-friendly website.

The collection includes tools for:

- Writing, editing and analysing text
- Formatting and converting development data
- Generating passwords, UUIDs, hashes and random values
- Resizing, compressing, cropping and editing images
- Working with colours, gradients and accessibility contrast
- Converting measurements, currencies, time zones and number systems
- Calculating loans, interest, tax, fuel costs, grades, dates and more

Every tool has its own dedicated page with:

- A clear explanation of what the tool does
- Practical examples and common use cases
- Step-by-step instructions
- Input validation
- Clear and reset controls
- Related tool recommendations
- Privacy information
- Accuracy and limitation notices

OpenToolbox is designed to be useful for students, writers, developers, designers, marketers, researchers, business owners and anyone who needs a quick browser-based utility.

# 🔒 Privacy and Local Processing

OpenToolbox follows a **local-first approach**.

For most tools:

- Text remains inside the visitor's browser.
- Calculations run locally using JavaScript.
- Images are processed through browser APIs and canvas.
- No OpenToolbox account is created.
- No OpenToolbox application database is used.
- No information is intentionally stored on an OpenToolbox server.
- No uploaded image is intentionally sent to an OpenToolbox application server.

This makes OpenToolbox suitable for quick everyday tasks where users prefer not to upload their content to a separate processing service.

## Tools Using External Resources

Two tools currently rely on external services or libraries:

### Currency Converter

The Currency Converter requests reference exchange-rate information from the [Frankfurter API](https://www.frankfurter.app/).

Rates are informational and may not match the final rate offered by a bank, payment provider, card issuer or currency exchange service.

### QR Code Generator

The QR Code Generator loads the MIT-licensed QRCode.js library from the jsDelivr content delivery network. QR rendering then takes place in the browser.

## GitHub Pages Hosting

The public website is hosted using GitHub Pages. GitHub may process standard technical and hosting information according to its own policies.

Read the project's full [Privacy Policy](privacy.html) for more information.

# 🚀 Deploy with GitHub Pages

OpenToolbox is designed to publish directly through GitHub Pages.

## GitHub Desktop Method

1. Download or clone the repository.
2. Open **GitHub Desktop**.
3. Add the project as a local repository.
4. Commit the project files to the `main` branch.
5. Select **Publish repository**.
6. Make the repository public.
7. Open the repository on GitHub.
8. Go to **Settings → Pages**.
9. Under **Build and deployment**, select:

```text
Source: Deploy from a branch
Branch: main
Folder: /(root)
```

10. Save the settings.
11. Wait for the GitHub Pages deployment to complete.

The default project address will follow this format:

```text
https://YOUR-USERNAME.github.io/open-browser-toolbox/
```

For this repository, the live address is:

### [https://bryanssss.github.io/open-browser-toolbox/](https://bryanssss.github.io/open-browser-toolbox/)

Detailed beginner-friendly instructions are available in:


# ⚠️ Accuracy and Responsible Use

OpenToolbox provides general-purpose utilities and informational estimates.

Results should be independently checked before being used for decisions involving:

- Medical care
- Personal health
- Financial commitments
- Tax reporting
- Legal matters
- Construction work
- Engineering
- Electrical work
- Commercial food-service compliance
- Safety-critical operations
- Academic grading
- Professional certification

Specific warnings include:

- The BMI Calculator is not a medical diagnosis.
- Financial calculators do not provide financial advice.
- Currency rates are reference values and may differ from transaction rates.
- Loan and mortgage estimates may not include every fee or lender condition.
- The Grease Trap Size Calculator does not replace local regulations, manufacturer instructions or professional sizing.
- Tax and VAT rules differ by location and may change.
- Image processing quality depends on the original file and browser support.
- Password generation does not replace good account security practices.
- JWT decoding does not verify a token's signature or authenticity.

Always verify important results using an appropriate professional, official source or specialist tool.
