## About OpenToolbox

**OpenToolbox** is a free and open-source collection of **122 browser-based tools** for writing, development, design, image processing, data conversion, accessibility checks, PDF inspection, dates, finance and everyday calculations.

The project is designed for people who need fast and dependable online utilities without installing software, creating an account or uploading private information to an application server.

Most processing happens locally on the visitor’s device using standard browser technologies.

### Project Principles

OpenToolbox is designed to remain:

- **Free** — every tool is available without a subscription.
- **Useful** — each utility solves a practical task.
- **Privacy-focused** — most text, files and settings stay inside the browser.
- **Browser-based** — no desktop application is required.
- **Accessible** — keyboard controls, semantic structure and visible focus states are included.
- **Mobile-friendly** — layouts work across phones, tablets, laptops and desktop computers.
- **Easy to deploy** — the project can run from static hosting without a production build.
- **Open source** — the code can be inspected, adapted and improved under the MIT Licence.

## Why Use OpenToolbox?

Many online utility websites require users to create an account, accept tracking, upload files to external servers or pay for basic features.

OpenToolbox offers a simpler alternative:

- Open the tool you need.
- Add text, values or a local file.
- Run the tool directly in the browser.
- Copy or download the result.
- Close the page when finished.

There is no account system and no required subscription.

## Privacy by Design

OpenToolbox is intentionally built without an application backend.

### What Stays Local

The following are normally processed or stored only on the visitor’s device:

- Text entered into tools
- Selected image files
- Selected PDF files
- Favourites
- Custom collections
- Usage history
- Category preferences
- Theme settings
- Interface settings
- Optional saved tool inputs

Local preferences use browser `localStorage`.

Visitors can export, import or delete their locally stored data from **My Toolbox**.

### Limited External Resources

Most OpenToolbox utilities work without contacting a third-party processing service.

A limited number of tools may use external public resources:

| Tool | External resource | Purpose |
|---|---|---|
| Currency Converter | Frankfurter API | Retrieves reference exchange-rate data |
| QR Code Generator | jsDelivr-hosted QRCode.js | Loads an MIT-licensed QR rendering library when required |

GitHub Pages may process ordinary hosting logs according to GitHub’s policies.

Read the complete [Privacy Policy](privacy.html).

## Deploy with GitHub Pages

### Deploy Using GitHub Desktop

1. Clone or open the `open-browser-toolbox` repository in GitHub Desktop.
2. Copy the updated project files into the local repository folder.
3. Review the changed files.
4. Commit the changes to the `main` branch.
5. Push the commit to GitHub.
6. Open the repository on GitHub.
7. Open **Settings**.
8. Select **Pages** under **Code and automation**.
9. Under **Build and deployment**, choose **Deploy from a branch**.
10. Select the `main` branch.
11. Select the `/ (root)` folder.
12. Save the settings.
13. Wait for GitHub Pages and GitHub Actions to complete.

The project does not require a production build command.

## Optional Custom Domain

OpenToolbox supports both its standard GitHub Pages address and an optional custom domain.

The project includes:

- [`docs/CUSTOM-DOMAIN.md`](docs/CUSTOM-DOMAIN.md)

### Basic Custom-Domain Process

1. Copy `CNAME.example`.
2. Rename the copy to `CNAME`.
3. Replace the example value with the chosen domain.
4. Commit and push the file.
5. Configure the required DNS records with the domain provider.
6. Add the domain under the repository’s GitHub Pages settings.
7. Enable HTTPS after GitHub validates the configuration.

## Accuracy and Responsible Use

OpenToolbox provides lightweight utilities, informational estimates and browser-based inspections.

Important results should be independently verified before they are used for:

- Financial decisions
- Legal work
- Tax work
- Accessibility certification
- Construction
- Engineering
- Safety-critical calculations
- Final document production

Financial calculators provide estimates rather than regulated financial advice.

Accessibility tools provide automated guidance rather than formal certification.
