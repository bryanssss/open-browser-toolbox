About the project

Free tools that respect your time.

OpenToolbox is an independent, open-source collection created by Boyan Minchev for GitHub Pages.

What makes it different

The repository uses plain HTML, CSS and JavaScript. There is no build command, package manager, user database or mandatory analytics service.

Independent implementation

The code, branding, written content and interface are original. The project provides common utility functions and does not reproduce another website's source code, branding or protected content.

Contributing

Open an issue or pull request on GitHub with a reproducible bug report or a clearly scoped improvement.
