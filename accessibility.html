Accessibility

Accessibility statement

OpenToolbox aims to remain usable with keyboards, screen readers and mobile devices.

Current measures

  • Visible focus states and labelled form controls.
  • Responsive layouts with no required horizontal scrolling.
  • High-contrast default colours and a light appearance option.
  • Semantic headings, landmarks and buttons.

Report a problem

Please open a GitHub issue with the affected page, browser, assistive technology and a clear description of the barrier.
