Accessibility

Read the accessibility features, known limits and testing approach for OpenToolbox.

Shared accessibility features

  • Skip links and semantic page landmarks
  • Visible keyboard focus
  • Keyboard shortcuts for search, running tools and navigation
  • Live result announcements
  • Responsive layouts with zoom-friendly text
  • Reduced-motion and larger-text preferences
  • Labels and guidance for interactive controls

Keyboard shortcuts

ShortcutAction
Ctrl/Command + KFocus tool search or return to the library
/Focus homepage search
Ctrl/Command + EnterRun the current tool
Alt + HReturn home
EscapeClose open dialogs

Automated and manual testing

The repository includes static audits and optional Playwright browser tests for navigation, keyboard access, responsive layout and basic accessibility checks. Automated checks cannot prove full accessibility; manual testing remains necessary.

Report a problem

Please open a GitHub issue with the page, browser, assistive technology and steps needed to reproduce the problem.
