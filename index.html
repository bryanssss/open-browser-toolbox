Project principles

Built to remain free and practical

🔒 Privacy-focused

Most tools process inputs locally. Optional local history, favourites and preferences never require an account.

📱 Accessible and responsive

Keyboard shortcuts, visible focus, screen-reader guidance and mobile layouts are part of the shared interface.

🌐 Browser-based and deployable

No build is needed for GitHub Pages. Offline caching and custom-domain documentation are included.
