Privacy

Understand what OpenToolbox stores locally and which tools use external resources.

Local processing

Most text, image, PDF and calculation inputs are processed on your device. OpenToolbox does not run an application server that receives those inputs.

Optional local data

Favourites, custom collections, tool history, settings, category order and optional saved form values are stored in browser local storage. You can export, import or delete this data from My Toolbox.

External resources

The currency converter requests reference exchange-rate data from the Frankfurter API. The QR Code Generator may load the MIT-licensed QRCode.js library from jsDelivr. GitHub Pages may process normal hosting logs under GitHub’s policies.

No advertising tracker included

The repository does not include analytics or advertising tracking by default.
