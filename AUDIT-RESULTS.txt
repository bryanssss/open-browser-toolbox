OpenToolbox V5.1 Design and Functional Audit
============================================

Release target: 122 browser tools across 7 categories
Validation date: 30 July 2026

DESIGN ISSUES FIXED
-------------------
- White dashboard cards appearing in dark mode
- White settings modal with unreadable near-white text
- Over-bright keyboard shortcut panel on dark tool pages
- Inconsistent card, field, result, table and button surfaces
- Unbalanced My Toolbox dashboard layout
- Mobile navigation opening while primary links remained hidden
- Colour-palette swatches being overridden by a compact swatch rule
- Saved theme being applied only after the stylesheet loaded
- Old cached CSS and JavaScript being shown after an update

FUNCTIONAL ISSUES FIXED
-----------------------
- Time Zone Converter now uses the selected source time zone
- Date and datetime defaults now use the visitor's local date/time
- Clear buttons reset text, file, select, checkbox, radio and range controls
- Data URI file encoding now processes larger files in safe chunks
- Empty readability input now reports zero sentences
- Theme controls update their icon, label, pressed state and browser theme colour
- Mobile navigation closes after selecting a link or pressing Escape

LOCAL BROWSER-RUN NOTE
----------------------
The execution environment used to prepare this package blocks Chromium from
opening localhost and file URLs with ERR_BLOCKED_BY_ADMINISTRATOR. The live
Playwright run therefore could not be executed locally here. The test suite is
valid JavaScript, is included in the repository, and runs in GitHub Actions
using an installed Chromium browser after the repository is pushed.
